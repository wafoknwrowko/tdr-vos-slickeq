## Overview

TDR VOS SlickEQ is a free, high-quality mixing EQ with three bands, shelving and bell modes, and a program-dependent saturation stage inspired by vintage analog equalizers.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TDR VOS SlickEQ** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three Bands** | Low, mid, and high EQ bands with shelf and bell types |
| **Saturation** | Four analog saturation models from transparent to colored |
| **Output Stage** | Separate gain and clipping control for drive and level staging |
| **Free Plugin** | Full-featured free version available from Tokyo Dawn Records |
